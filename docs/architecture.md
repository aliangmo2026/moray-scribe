# moray-scribe 架构说明

moray-scribe 把"看懂遗留 Python 项目"拆成五段，前四段是确定性引擎，只有语义描述交给本机大模型，且模型只能输出一份 Pydantic 强校验的 JSON。

**五层流水线**：① 扫描（libcst 提取模块/类/函数/继承/导入/调用）→ ② 建图（PageRank 枢纽、死代码、入口点，按 Token 预算裁剪；边宁缺毋滥，含糊关系跳过并在"已知缺口"标注）→ ③ 描述（本地 Ollama 产出 JSON 草稿，校验失败带反馈重试）→ ④ 渲染（ARCHITECTURE.md + 可粘贴 mermaid.live 的 .mmd，可复现）→ ⑤ MCP（6 个 tool 挂到宿主）。

**AI / 引擎分区**：文档里"AI 推理"章节（概览、架构图、模块说明）来自模型，"引擎统计"章节（枢纽、死代码等）来自静态分析，显式分栏，读者清楚哪部分可信、哪部分是推断。

**为什么用 libcst**：它保留注释、格式与精确源位置，符号能回溯到真实代码行；相比标准库 `ast`，对现代 Python 语法支持更全。
