# 接手同事留下的屎山代码？我做了个工具让它自己画图自己讲解🐣

小红书/即刻小白风 · 3 分钟看懂一个老项目

姐妹们！程序员的痛苦我来说一句：😱

接手一个**几万行、没文档、原作者跑路**的老项目，
是不是感觉像被扔进了一间关灯的仓库？

问 AI 吧——它只会"打开一个文件讲一个文件"，
讲完你还是不知道这个项目到底是怎么转起来的🙃

## 💡 所以我做了一个开源小工具：moray-scribe

一句话：**让老项目自己画出自己的地图**🗺️

✨ 跑一条命令，它会给你：

1️⃣ 一张**彩色的架构图**：哪些是核心模块、哪些是边角料，一目了然
2️⃣ 一份**中文说明书**：每个模块负责干嘛、哪里最危险、哪里可能是死代码
3️⃣ 一组**业务流程动画图**：比如"用户登录"从头到尾经过了哪些函数
4️⃣ 一个**可以拖来拖去的地图页面** + 一个**聊天框**：
    直接问它"我改登录功能会影响哪里？"——它会告诉你哪些地方会中枪🎯

## 🔒 最重要的一点：代码不出你的电脑！

它用的是你自己电脑上的本地 AI（Ollama），
**不联网、不上传、不收费**——公司代码也能放心用✅

## 🚀 三分钟上手

怕装环境的姐妹直接用 Docker（一行命令）：

```
docker compose up
```
然后打开 localhost:8000，就能看到项目的彩色地图+问答框🥳

不想装 Docker？双击我们准备好的安装脚本（Windows/Mac 都有），
它自己会搞定一切～

## 🎁 适合谁

✅ 刚接手老项目的打工人（第一周就摸清全局）
✅ 要写"系统设计文档"交差的人（它帮你写初稿！）
✅ 想清理死代码但不敢删的人（它标出"没人调用"的函数，删前再人工确认）
